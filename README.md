# VowCraft — Smart Event & Wedding Planner 💍✨

A modern, glassmorphic interactive web dashboard for planning large-scale weddings and events built with **HTML5, CSS3, and Vanilla JavaScript**.

## 🌟 Key Features
* **Real-time Event Countdown:** Live dynamic timer calculating days, hours, and minutes remaining for the big event.
* **Interactive Guest & RSVP Hub:** Add, filter, and track guest attendance, diet preferences, and plus-ones.
* **Expense & Budget Tracker:** Visual allocation breakdown for catering, venue, decor, and photography.
* **Itinerary & Timeline:** Sequential chronological flow for event milestones.
* **Seating Allocation Cards:** Grid layout previewing table assignments for attendees.

## 🛠️ Tech Stack
* **HTML5:** Semantic architecture & modal views.
* **CSS3:** Custom CSS variables, Glassmorphism backdrop filter, Flexbox & Grid layouts.
* **JavaScript (ES6):** Dynamic DOM updates, live event counter, array filtration algorithms.

## 🚀 Quick Start & Deployment
1. Download or clone this repository.
2. Put all files (`index.html`, `style.css`, `script.js`, `README.md`) inside a single directory.
3. Open `index.html` directly in any web browser or deploy with GitHub Pages!
